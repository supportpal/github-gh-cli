# Security Policy

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

## Supported Versions

Only the latest release is supported. Security fixes are not backported to older versions.

## Reporting a Vulnerability

Report vulnerabilities privately using GitHub's built-in reporting:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Include steps to reproduce, affected version(s), and potential impact.
